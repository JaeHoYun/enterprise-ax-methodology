# 기업용 AX(AI Transformation) 방법론 가이드

AX에 착수하기 전 단계에서 무엇을 살펴보고, 어떻게 문제를 정의하며, 그다음에 어떤 선택지가 있는지를 큰 그림으로 안내하는 공개 가이드입니다. 중심은 문제 정의입니다. 과제가 산적한 기업이 어떤 시선으로 무엇을 살펴보고 어떻게 문제를 정의할지를 앞부분에서 다루고, 누가 풀 것인가와 어디서 돌릴 것인가는 그다음에 오는 선택으로 뒷부분에서 다룹니다.

이 가이드는 AI 컨설팅을 대체하지 않고, 채워 쓰는 양식을 제공하지 않으며, 특정 제품이나 모델을 전제하지 않습니다. 가이드의 접근이 맞지 않는 조건도 본문에 함께 적었습니다.

## 누구를 위한 가이드인가

- **주 독자.** AX 추진 조직의 리더와 실무 기획자, 현업 부서에서 변화를 이끄는 분
- **보조 독자.** 임원. [00장](docs/00-orientation.md)과 각 장 첫머리의 요약만 읽어도 큰 그림이 잡히도록 구성했습니다.
- **대상이 아닌 독자.** 플랫폼과 인프라를 책임지는 분은 아래 관련 가이드를 참고하시기 바랍니다.

## 주요 용어

| 용어 | 설명 |
|------|------|
| **AX** | AI Transformation. 업무의 판단과 실행을 AI로 돕거나 AI에 맡기는 전환 |
| **문제 정의문** | 누가, 어떤 판단이나 흐름에서, 현재 기준선, 성공의 모습, 소유자, 두 관문 질문의 답을 한 쪽 안에 적은 글 |
| **관문 질문** | 검증에 들어가기 전에 묻는 두 질문. 왜 지금까지 못 풀었는가, AI가 아니어도 풀리는가 |
| **가치 가설** | 누가, 어떤 업무에서, 무엇이 얼마나 좋아질지를 검증할 수 있게 적은 가정 |
| **최소 관통 파일럿** | 한 업무를 처음부터 끝까지 관통하되 범위는 최소로 좁힌 파일럿 |
| **게이트** | 파일럿을 계속할지 멈출지를 미리 정한 기준으로 판정하는 관문 |
| **이양** | 외부가 맡던 개발과 운영을 내부 인력이 넘겨받는 일 |
| **수요 확인 후 플랫폼 구축** | 공통 기반을 미리 짓지 않고, 여러 과제의 공통 수요가 드러난 부분부터 공통화하는 원칙 |

그 밖의 용어는 각 장에서 처음 나오는 곳에 풀어 썼습니다.
